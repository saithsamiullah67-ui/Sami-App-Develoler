# Sami App Creator — Foundation

Run with Node.js 18+:
1. `npm install`
2. `npm start`
3. Open `http://localhost:3000`

Includes the creator website, project workspace, screen planner/editor, preview, browser-local save, JSON export, and a small Express backend.

This is the foundation, not yet a complete arbitrary app compiler. Cloud accounts, shared database, external AI, APK/AAB builds/signing, and store publishing require separate modules and infrastructure.
